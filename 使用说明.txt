【桐花巷小站 · 使用说明】

打开网站（任选其一）：
- 方式一（最简单）：双击「桐花巷小站.html」，无需安装任何东西
- 方式二（开发版）：双击「启动网站.bat」，自动打开 http://localhost:5173

============================================================
一、怎么改「微信号」？
============================================================
用记事本打开  src\config.js，找到这一行：

    wechatId: 'tonghuaxiang',   // ← 在这里改成你的微信号

例如改成  wechatId: 'momo_2026',  保存后重新生成单文件即可（见文末）。

============================================================
二、怎么换「摄影作品」？
============================================================
1. 把你的照片放进 public\photos\ 文件夹，覆盖同名文件即可：
   photo-1.svg … photo-10.svg（10 张 = 一排 2 张 × 5 排）
   —— 如果你的照片是 jpg/png 也没关系，把文件名改成 photo-1.svg 那样的
      数字编号就行（如 photo-1.jpg、photo-1.png 都可以，但路径要同步改）。
2. 想改照片的标题/日期：编辑 src\config.js 里 photos.items 数组：
     { src: '/photos/photo-1.svg', title: '晴天与单车', date: '2026.07' },
   把 title / date 换成你想要的。
3. 想增加/减少照片数量：在 config.js 的 photos.items 里增删条目，
   并把 public\photos 里的图片编号保持一致。

============================================================
三、怎么换「明信片」（一套 8 张）？
============================================================
1. 把你的明信片图放进 public\postcards\ 覆盖同名文件：
   postcard-1.svg … postcard-8.svg
2. 想改明信片的名字/标签：编辑 src\config.js 里 postcards.items：
     { src: '/postcards/postcard-1.svg', name: '海边的风', tag: '人气款' },
   tag 留空 '' 就不显示小标签。
3. 想改张数：增删 items 条目 + 对应图片（网格会自动重排）。

============================================================
四、怎么改「定价」？
============================================================
在 src\config.js 里：
    price: '¥ 6.9 / 张',            ← 单价
    priceNote: '一套 8 张 ¥ 49 · 也可以单张买 · 可指定祝福语',  ← 补充说明
直接改成你想要的文字即可。

============================================================
五、改完怎么让网站生效？
============================================================
单文件「桐花巷小站.html」是打包好的，改完代码后需要重新生成。
两种方式：
- 双击「启动网站.bat」用开发版看效果（实时生效，不用重新打包）
- 生成新单文件：需要安装 Node.js 后，在项目文件夹执行：
      pnpm build
      node work\inline-site.mjs
  然后双击新的「桐花巷小站.html」即可。

============================================================
六、微信二维码
============================================================
把真实二维码图片放到 public\wechat-qr.png，
再把 src\components\PostcardSection.jsx 里的 <FakeQr /> 换成
<img src="/wechat-qr.png" alt="微信二维码" />，重新生成单文件。
